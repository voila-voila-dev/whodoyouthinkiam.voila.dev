# Who Do You Think I Am?

A couples perception game — two people rate each other's personality on 8 axes, then reveal the gaps.

> **Package manager: [Bun](https://bun.sh/)** — do not use npm or pnpm.

## Getting Started

```bash
bun install
bun run dev
```

## Scripts

```bash
bun run dev       # Start dev server on port 3000
bun run build     # Production build
bun run preview   # Preview production build
bun run test      # Run tests
bun run lint      # Lint with Biome
bun run format    # Format with Biome
bun run check     # Biome check (lint + format)
```

## Tech Stack

- **Framework:** React 19 + TanStack Router (file-based routing)
- **State:** Effect-Atom
- **Styling:** Tailwind CSS 4
- **Build:** Vite
- **Linting:** Biome
- **Testing:** Vitest
